# Assets Folder

Place your custom assets here to enhance your reels.

## Structure

```
assets/
├── music/          # Background music files (.mp3)
├── images/         # Background images (.jpg, .png)
└── fonts/          # Custom fonts (.ttf)
```

## Music Files

Place royalty-free background music here:
- **Format:** MP3
- **Length:** 15-30 seconds
- **License:** Ensure you have rights to use

### Free Music Sources:
- YouTube Audio Library
- Pixabay Music
- Incompetech
- Free Music Archive

## Images

Place background images here:
- **Format:** JPG or PNG
- **Size:** 1080x1920 (9:16 ratio)
- **Quality:** High resolution

### Free Image Sources:
- Unsplash
- Pexels
- Pixabay
- Freepik

## Fonts

Place custom fonts here:
- **Format:** TTF or OTF
- **License:** Ensure commercial use allowed

### Free Font Sources:
- Google Fonts
- DaFont
- Font Squirrel
- 1001 Fonts

## Usage

Files in this folder will be automatically detected by the video generator (future feature).
